# Operations Hub

Medical Supply Operations Platform

## Overview

Operations Hub is a prototype designed to replace a fragile spreadsheet-based workflow used to manage patient orders, pricing calculations, approvals, and document generation.

The project was created as part of a Product Manager case study and focuses on:

- Product thinking
- Workflow optimization
- MVP prioritization
- Operational efficiency
- Future AI-enabled opportunities

## Scope

### MVP
- Order Intake
- Product & Pricing Catalog
- Pricing Engine
- Approval Workflow
- Document Generation
- Operations Dashboard

### Future Opportunities
- Vendor Automation
- AI Recommendations
- Prior Authorization Detection
- Intelligent Workflow Assistance

## Notes

This is a prototype built with mock data and does not contain production integrations, authentication, or backend services.
